# Devpost copy · Rate Plain · Code for Change

## Tagline
BoC rates and a plain renewal checklist on one screen.

## Inspiration
Renewal letters arrive dense. Public rate data already exists at the Bank of Canada. I wanted those series next to a household timeline in language anyone can use, without pretending to quote a lender.

## What it does
Charts the BoC policy rate and the 5-year benchmark bond yield, shows the latest prints, and turns a balance, current rate and renewal date into plain next steps with an illustrative interest-only sketch that is labelled as not a payment quote.

## How we built it
Static site. Valet JSON cached in `data/` with source URLs. Canvas chart. No backend.

## Challenges we ran into
Staying useful without crossing into advice. Keeping the math honest by using a simple sketch and saying so.

## Accomplishments that we're proud of
Live public series, clear citations, mobile layout, one-screen story.

## What we learned
Impact here is clarity. A dated public number beats a vague claim.

## What's next
Optional live Valet refresh and a printable checklist.

## Built with
HTML, CSS, JavaScript, Bank of Canada Valet API
